# Project Overview

This is a TUI version of the writing tool from hundredrabbits as found [Here](https://github.com/hundredrabbits/Left)
That version was a writing editor built using electron as a standalone app.

I wanted to try my hand at recreating it as a TUI app instead as a learning exercise.

## Tools used

This is a TUI app built in Rust making use of crossterm and ratatui to function on terminals.

# Running the app

To run, name a txt file you want to edit

```bash
cargo run -- test.txt
```
